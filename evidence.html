01 / OBJECT

Die Bleimasken

Zwei handgemachte Abdeckungen über den Augen. Das stärkste Bild des Falls — und sein stummstes Beweisstück.

02 / OBJECT

Eine Wasserflasche

Ein gewöhnlicher Gegenstand, der die Route konkret macht: auf dem Hügel wollten Menschen Zeit verbringen.

03 / OBJECT

Die Notiz

Eine Liste von Zeiten, eine Kapsel, Schutz und ein Signal. Ein paar Zeilen, die Jahrzehnte des Rätselns zeugten.

04 / OBJECT

Die Mäntel

Ein ebenso praktisches wie unheimliches Detail: Regenkleidung an einem Tag ohne bekanntes Unwetter.

Die Zeit

Die Uhren und die Angaben der Notiz fügen sich nicht zu einem einfachen Bild. Das wichtigste Beweisstück — der Zwischenraum.

Inventarnotiz

Gegenstände müssen nicht einen einzigen Sinn haben.

Wasser kann Wasser sein. Ein Mantel — ein Mantel. Eine Bleimaske ist nicht unbedingt ein Schlüssel zu einer anderen Zivilisation. Ein Beweisstück wird erst nach der Interpretation zur Theorie.
